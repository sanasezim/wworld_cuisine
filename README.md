# World Cuisine

World Cuisine is a responsive multi-page website created for the Web Technologies 1 Front-End course.

The purpose of the project is to introduce users to popular cuisines, dishes, recipes, and restaurants from different countries around the world.

The website is designed for desktop, tablet, and mobile devices using HTML, CSS, Flexbox, CSS Grid, Media Queries, and Bootstrap.

Main features:

- Responsive Bootstrap Navbar
- Hero section
- Bootstrap Grid
- Bootstrap buttons
- Bootstrap Cards
- Responsive layout for desktop, tablet, and mobile
